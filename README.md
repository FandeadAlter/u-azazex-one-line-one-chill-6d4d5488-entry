A program that writes a single line of horror — one sentence, under 200 characters — to `/output/entry.txt`.

Bounty: [One Line, One Chill on make.fun](https://make.fun/c/u-azazex-one-line-one-chill-6d4d5488)

## The line

> The last page of my diary, in my handwriting, describes tomorrow.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (65 characters, one sentence).
